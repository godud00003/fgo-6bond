# FGO 인연 파티 최적화 (한국 서버)

퀘스트명을 입력하면 인연 예장만 끼고도 클리어되는 파티 중 인연 포인트 합계가 가장 큰 구성을 찾는 웹 앱.

## 실행

```bash
npm install
npm run dev
```

## 배포용 단일 파일

```bash
npm run single
```

`fgo-bond.html` 파일 하나가 만들어진다(약 1.8MB). 스크립트·스타일·게임 데이터가 모두 들어 있어 더블클릭으로 바로 열리고 서버가 필요 없다. 적 구성 조회와 아이콘 표시에는 인터넷 연결이 필요하다. 설정과 보유 현황은 파일을 연 브라우저에 저장된다.

게임 데이터(`public/data/`)는 포함되어 있다. 한국 서버 업데이트 후 갱신하려면 `npm run data`.

## 내 계정 불러오기

"내 서번트" 탭의 "게임 로그인 데이터 가져오기"에 게임 로그인 응답 파일(Chaldea의 HTTPS 스니핑 가져오기와 같은 형식, 예: `fgo_login_kr.txt`)을 넣으면 보유 서번트, 레벨·ATK(포우 포함)·보구 레벨·스킬별 레벨·어펜드 2, 인연 레벨(인연 MAX·인연 15), 보유 인연 예장과 해방 여부, 코스트 상한이 한 번에 채워진다. 파일은 브라우저 안에서만 읽고 필요한 수치만 localStorage에 저장한다. 이 파일에는 계정 정보가 들어 있으니 저장소에 넣지 않는다.

## 구조

- `scripts/build-data.mjs` — Atlas Academy 원본을 앱용 JSON으로 변환
- `src/engine/quest.ts` — 퀘스트명 해석("2부 6장 4절 2번째 배틀"), 적 데이터 변환
- `src/engine/sim.ts` — 보구 전용 전투 시뮬레이터(클리어 판정)
- `src/engine/search.ts` — 전열 조합 탐색 + 인연 포인트 최적화
- `src/engine/importLogin.ts` — 게임 로그인 데이터에서 보유 현황 추출
- `src/App.tsx` — 화면
- `test/run.ts` — 명령줄 검증: `node test/run.ts "2부 6장 4절 2번째 배틀"`

## 계산 전제

- 적 구성은 같은 퀘스트 ID의 일본 서버 데이터를 쓴다(한국 서버 데이터에는 적 정보가 없음).
- 메인 퀘스트·프리 퀘스트와 칼데아 게이트 요일 퀘스트(종화 수집, 수련장, 보물창고)를 검색할 수 있다. 요일 퀘스트의 적 클래스는 판마다 달라질 수 있고, 데이터에는 한 가지 구성만 있다.
- 인연 포인트 = 내림(내림(기본치 × (1 + 전열 보너스)) × (1 + % 보너스 합)) + 고정치 합. % 끼리는 합연산, 상한 300%.
- 전열 보너스: 전열에 선 내 서번트 본인 +20%, 프렌드 서포트가 전열이면 파티 전원 +4%. 계산식은 Chaldea(chaldea-center/chaldea)의 인연 계산과 한국 서버 게임 상수를 따랐다.
- 인연 15인 내 서번트는 1기마다 파티 전원 +25%(예장 %와 합산). 찻주전자는 최종값에 배수로 곱한다.
- 이벤트·캠페인 보너스는 계산하지 않는다.
- 클리어 판정은 보구 대미지와 NP 수급만 본다. 평타 대미지와 적의 행동은 계산하지 않는다.
- 오버차지: NP 100%마다 1단계(최대 3) + 같은 턴 보구 연계 순서 + 오버차지 UP 버프, 최대 5단계. 단계별 수치는 게임 데이터 그대로 쓴다.
- 어펜드 스킬 5(스킬 재장전): 스킬마다 처음 쓸 때 쿨타임 1 감소. 가져온 서번트는 실제 레벨(Lv1~5 1회, 6~9 2회, 10 3회), 그 외와 프렌드는 설정을 따른다. 쿨타임 단축 스킬은 다른 스킬을 쓴 뒤에 쓰고, 그 턴에 다시 쓸 수 있게 된 스킬은 이어서 쓴다.
- 특공: 대상 특성 특공, 상태 특공(대상에게 걸린 상태), 중첩 특공(특성·상태 수에 비례, 상한 적용), 레어도 특공, 복수 특성 동시 충족 특공. 특성 부여 버프와 필드 특성 변경을 반영한다.
- NP 충전 변형: 특성·상태 수에 비례하는 충전, 배율 충전, 다른 아군의 NP를 가져오는 충전.
- 적 패시브: 특성 부여, 방어력 증감, 보구 대미지 내성, 고정 대미지 컷, 회피·무적(필중·무적 관통이 없으면 대미지 0).
- 아직 계산하지 않는 것: 공격 시 발동하는 추가 효과, 보구 카드 종류 변경(에미야·스페이스 이슈타르), 변신, 클래스 상성 변경, HP에 비례하는 보구 대미지. 효과 종류와 규칙은 Chaldea의 전투 코드를 기준으로 맞췄다.
- 스킬 제약: 선쿨타임(배틀 개시 시 바로 쓸 수 없는 스킬)과 "NP가 일정 % 이상" 사용 조건을 지킨다. 스타 수나 낮은 HP를 요구하는 스킬·효과, HP가 줄어야 켜지는 버프는 쓰지 않는 것으로 본다. 여러 효과 중 하나를 고르는 스킬은 보구 대미지에 가장 유리한 선택지 하나만 적용한다. 특성 조건이 붙은 버프는 보유자나 필드가 그 특성을 가질 때만 건다.
- 마술예장은 레벨 10 스킬로 계산한다. "자동 선택"(기본)은 예장 없이 먼저 계산하고, 안 되는 편성에만 이 퀘스트에서 가장 도움이 되는 예장 하나를 쓴다. 도움이 되는 예장은 대표 편성(대미지 상위 딜러 12기 × 단독·캐스토리아 2기)으로 점수를 매겨 고른다.
- 오더 체인지("오더 체인지 사용"을 켰을 때만, 오더 체인지가 있는 예장으로만): 서포터 하나의 스킬을 모두 쓴 뒤 후열의 다른 서포터와 바꾸는 편성을 찾는다. 들어온 서포터는 같은 턴에 스킬을 쓴다.
- 보구를 쓰면 퇴장하는 서번트(아라쉬, 오다 노부카츠, 시즈키 소쥬로, 투탕카멘은 자신이, 진궁은 선두의 다른 아군이 퇴장)는 빈자리에 후열 선두가 들어온다. 이들을 앞세우고 후열에 서포터를 둔 편성도 찾는다.
- 후열에서 시작하는 교체 요원은 전열 인연 보너스(+20%)를 받지 못하고, 프렌드가 후열이면 전원 +4%도 없다.
- 오베론: 보구에 맞은 적은 그 턴 동안 무적이 되어 뒤따르는 보구가 막힌다(그래서 오베론 보구는 맨 뒤에 쏜다). "꿈의 끝"의 보구 위력 부스트는 중복되지 않고, 대상은 턴이 끝나면 강화가 풀리고 영구수면에 빠지므로 마지막 웨이브나 곧 퇴장할 서번트에게만 쓴다. "아침의 종다리"는 턴 종료 시 NP 20% 감소를 반영한다.
- 예장 ATK: 예장 없이 클리어되는 편성은 그대로 두고, 안 되는 편성은 보유 인연 예장 중 ATK가 가장 높은 것을 주 딜러에게 끼운 조건으로 다시 계산한다. 그 편성은 해당 예장을 반드시 포함하도록 인연을 최적화하고, 결과에 누구에게 끼울지 표시한다. 예장 ATK는 가져온 실제 수치, 없으면 최대 레벨 기준.
- 브레이크 게이지는 보구 한 번에 한 줄씩만 깎인다고 본다. 권장 턴 수는 게이지 줄 수를 반영하고, 실패 시 몇 줄까지 깎았는지 보여 준다.
- "전원 레벨 1 고정"을 켜면 출전 서번트(프렌드 포함)의 ATK를 레벨 1 수치 + 포우 강화로 계산한다. 스킬·보구 레벨은 그대로 둔다. 2부 6장의 레벨 1 기믹 전투용.
- 증원(전투 중 소환되는 적)도 계산한다. 적 AI는 필드에 빈자리가 있으면 같은 증원을 반복 소환하므로, 소환하는 적이 살아 있는 한 턴이 끝날 때 빈자리가 다시 채워진다고 본다. 자기 소환 목록을 가진 적은 웨이브 시작 때도 소환한다. 실제 소환 시점은 적 AI마다 조금씩 다를 수 있다.
- 평타로 얻는 NP는 계산하지 않는다. 대신 "보구를 안 쓴 턴마다 N%"라는 가정치를 줄 수 있다(기본 0%).
- "반드시 포함할 서번트"에 고른 서번트(최대 5기)는 내 파티에 반드시 들어간다. 딜러·서포터로 쓰이지 않으면 인연을 받는 자리에 넣는다. 프렌드 자리는 해당하지 않는다.
- "동일 서번트 편성 허용"을 끄면 프렌드로 내 파티와 같은 서번트를 빌리는 편성(같은 딜러 2기, 같은 서포터 2기)을 후보에서 뺀다.
- 프렌드로 딜러와 같은 서번트를 빌려 보구를 번갈아 쓰는 편성도 찾는다.
- 딜러 1기 + 서포터로 안 되면 딜러 여러 기 편성을 찾는다: 내 딜러 2기 + 서포터, 같은 딜러 2기(내 것 + 프렌드) + 다른 딜러, 내 딜러 3기. 후보는 혼자서 준 대미지가 큰 딜러 14기와 마지막 웨이브 보스에게 강한 딜러 8기. 프렌드 딜러의 보구 레벨은 1로 가정한다.
- 실제 주회와 대조한 사례: 종화 수집 극급(3웨이브 보스 버서커), 로우히 2기 + 어둠의 코얀스카야, 마술협회 제복. 평타 NP 가정 없이 최저 난수에서 실제와 같은 순서(1·2턴 로우히 보구, 3턴 코얀스카야 보구)로 3턴 클리어가 나온다.
- 서번트 특성에는 나중에 추가된 상시 특성(traitAdd)도 포함한다. 조건부 인연 예장과 특성 한정 버프 판정에 쓰인다.
- 영기재림 단계(모습)에 따라 특성이 달라지는 서번트는 단계별 특성을 따로 갖는다(예: 로우히는 3·4단계에서만 [짐승과의 서번트]). 등록한 단계가 없으면 4단계 기준.
- 인연 계산을 실제 결과와 대조한 사례: 종화 수집 극급, NFF에서 사랑을 담아(내 것+프렌드), 명탐정 폼즈, 시크릿 미션, 칼데아 런치타임, 영령초상. 다섯 서번트의 획득량(1,423 / 1,423 / 1,350 / 1,350 / 1,201)이 모두 일치.
