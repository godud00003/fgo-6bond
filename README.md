# FGO 인연 파티 최적화 (한국 서버)

퀘스트를 고르면, **인연 예장만 끼고도 클리어되는 파티** 중에서 **인연 포인트 합계가 가장 큰 편성**을 찾아 줍니다. 스킬과 보구를 어떤 순서로 쓰면 되는지도 턴별로 보여 줍니다.

**바로 쓰기: https://godud00003.github.io/fgo-6bond/**

설치할 것은 없습니다. 주소를 열면 되고, 프로그램과 게임 데이터는 자동으로 최신이 됩니다. 인터넷 없이 보관하고 싶으면 [파일 하나짜리 버전](https://godud00003.github.io/fgo-6bond/fgo-bond.html)을 저장해서 더블클릭으로 열 수 있습니다.

## 빠른 시작

1. **퀘스트 찾기** — 검색창에 퀘스트를 적고 "찾기"를 누릅니다. 후보가 여럿이면 하나를 고릅니다.
2. **조건 확인** — 서번트 풀, 턴 제한, 마술예장 등을 정합니다. 처음에는 기본값 그대로 두어도 됩니다.
3. **최적 파티 찾기** — 5~15초쯤 뒤 추천 파티가 인연 합계가 큰 순서로 나옵니다.

### 퀘스트 검색어 예시

| 적는 법 | 찾는 것 |
|---|---|
| `2부 6장 4절 2번째 배틀` | 메인 퀘스트의 특정 전투 |
| `아발론 프리` | 그 장의 프리 퀘스트 전체 |
| `솔즈베리` | 지명이나 퀘스트 이름 |
| `종화 수집 극급`, `창의 수련장 극급` | 칼데아 게이트 요일 퀘스트 |
| `SAITAMA 탐문 조사` | 진행 중인 이벤트의 반복 퀘스트 |
| `강화 퀘스트 멀린`, `강퀘 스파르타쿠스` | 서번트 강화 퀘스트 |
| `막간 오베론`, `인연퀘 알트리아 펜드래곤` | 막간의 이야기(영기해방 퀘스트 포함) |

강화 퀘스트와 막간의 이야기는 해당 서번트를 편성해야 하므로, 그 서번트가 들어간 편성만 찾습니다.

## 내 계정 불러오기

기본은 "한국 서버 전체 서번트" 기준입니다. 내가 가진 서번트로만 계산하려면 **내 서번트** 탭에서 등록합니다.

**계정 데이터 가져오기** 버튼에 아래 파일 중 하나를 넣으면 보유 서번트, 레벨·보구·스킬·어펜드, 인연 레벨, 보유 인연 예장, 클래스 스코어가 한 번에 채워집니다.

| 파일 | 특징 |
|---|---|
| 게임 로그인 응답 파일 (예: `fgo_login_kr.txt`) | 가장 정확합니다. 레벨, 실제 ATK, 코스트 상한까지 들어 있습니다. |
| Chaldea 앱 백업 (`chaldea-userdata-….json`) | 레벨이 없어 재림 단계와 성배 수로 추정합니다. 다 키운 서번트는 정확합니다. |

- 파일은 **내 브라우저 안에서만** 읽습니다. 어디로도 전송하지 않습니다.
- 가져오면 기존에 등록한 내용을 덮어씁니다.
- 손으로 하나씩 체크해서 등록할 수도 있습니다.
- **인연 MAX**로 표시된 서번트는 전투에는 쓰지만 인연 합계에서 빠집니다. **인연 15**인 서번트는 파티에 있으면 다른 파티원의 인연이 25% 늘어납니다.

등록한 내용은 그 브라우저에 저장됩니다. 다른 브라우저나 다른 기기에서는 다시 가져와야 합니다. "백업 내보내기"로 파일로 옮길 수 있습니다.

## 조건 설명

| 항목 | 뜻 |
|---|---|
| 서번트 풀 | 한국 서버 전체 / 내 보유 서번트만 |
| 턴 제한 | 이 턴 안에 깨지는 편성만 찾습니다. 퀘스트를 고르면 권장값이 들어갑니다. |
| 파티 코스트 상한 | 내 마스터 레벨의 코스트 상한. 로그인 데이터를 가져오면 자동으로 맞춰집니다. |
| 대미지 난수 | 최저(0.9)는 운이 나빠도 깨지는 편성, 평균(1.0)은 보통 운 기준입니다. |
| 프렌드 서포트의 예장 | 프렌드가 낀 인연 예장. "자동 선택"은 어떤 예장을 낀 프렌드를 빌리면 가장 좋은지 찾아 줍니다. 프렌드가 시작 NP 예장(칼레이도스코프 등)을 낀 경우도 고를 수 있습니다. |
| 마술예장 | "자동 선택"은 예장 없이 먼저 계산하고, 안 되는 편성에만 가장 도움이 되는 예장을 씁니다. 가진 예장으로 보려면 직접 고르세요. |
| 찻주전자 | 인연 2배·3배 |
| 반드시 포함할 서번트 | 고른 서번트(최대 5기)가 들어간 편성만 찾습니다. |
| 전원 레벨 1 고정 | 2부 6장의 레벨 1 기믹 전투용. 직접 켜야 하고, 끝나면 꺼 주세요. |
| 동일 서번트 편성 허용 | 프렌드로 내 파티와 같은 서번트를 빌리는 편성(같은 딜러 2기 등)을 넣을지 |
| 오더 체인지 사용 | 서포터를 교체하는 편성도 찾습니다. 전투복·결전용 제복이 필요하고, 계산이 더 오래 걸립니다. |
| 령주 1획 사용 | 령주로 아군 한 명의 NP를 100% 채우는 편성도 찾습니다. 령주 없이 되는 편성에는 쓰지 않고, 써야 하는 편성에는 표시가 붙습니다. 계산이 더 오래 걸립니다. |
| 보구 조합 탐색 | 정해진 운용으로 안 깨지는 편성은 턴마다 누가 보구를 쏠지 바꿔 가며 다시 찾습니다. 서포터가 보구를 쓰는 경우(제갈공명·알트리아 캐스터의 버프·디버프 보구 포함)와 한 턴에 보구 2~3개를 함께 쏘는 경우(같은 딜러 2기가 동시에 쏘기 등)가 들어갑니다. 기본으로 켜져 있고, 끄면 계산이 2~3배 빨라집니다. 계산은 CPU 코어 수에 맞춰 여러 개로 나눠 동시에 돌립니다. |
| 클래스 스코어 (내 서번트 / 프렌드) | 클래스 스코어의 카드 위력 UP·보구 위력 UP 칸을 대미지에 반영합니다. 계정 데이터를 가져오면 "가져온 내 데이터"로 실제 연 칸 기준 계산이 됩니다. 프렌드 서번트에는 프렌드의 클래스 스코어가 적용되므로 따로 고릅니다. |
| 미등록 서번트: 어펜드 2 / 5 | 등록하지 않은 서번트가 어펜드를 열었다고 볼지 |
| 프렌드: 어펜드 2 / 5 | 빌리는 프렌드가 어펜드를 열었는지. 결과를 가르는 경우가 많으니 실제 프렌드에 맞추세요. |

## 결과 읽는 법

- 게임의 편성 화면처럼 **전열 3칸, 후열 3칸**으로 나옵니다. 프렌드는 실제로 서는 자리에 표시됩니다.
- 칸마다 **그 서번트가 끼울 인연 예장**이 아이콘으로 붙어 있습니다. 인연 효과는 누가 껴도 같지만, 테두리가 표시된 예장은 그 딜러에게 끼워야 대미지가 모자라지 않습니다.
- **마술예장** 줄에 예장이 나오면 그 예장의 스킬을 써야 깨집니다. "아무거나"면 예장 스킬 없이 깨집니다.
- "자세히"를 누르면 **턴별 스킬·보구 순서**가 나옵니다. 같은 서번트가 둘이면 프렌드 쪽에 "(프렌드)"가 붙습니다.
- "교체 투입"은 후열에서 시작해 전투 중 들어오는 서번트입니다. 후열 맨 앞 칸에 두세요.

결과가 하나도 안 나오면 화면의 안내대로 마술예장을 자동 선택으로 바꾸거나, 턴 제한을 늘리거나, 오더 체인지를 켜 보세요.

## 알아 둘 한계

이 계산기는 **보구와 스킬만으로** 클리어 여부를 판정합니다.

- **평타는 계산하지 않습니다.** 실제로는 평타로 마무리되는 전투도 "불가능"으로 나올 수 있습니다. 반대로 여기서 깨진다고 나온 편성은 평타 운과 무관하게 깨지는 편성입니다.
- **적의 공격은 계산하지 않습니다.** 아군이 쓰러지지 않는다고 봅니다.
- **확률로 걸리는 효과는 실패한 것으로 봅니다.**
- **적 구성은 일본 서버 데이터를 씁니다.** 한국 서버 데이터에는 적 정보가 없어 같은 퀘스트의 일본 서버 구성을 가져옵니다. 적 클래스가 판마다 바뀌는 퀘스트(종화 수집 랜덤 편 등)는 기록된 한 가지 구성 기준입니다.
- **프렌드는 보구 1, 스킬 10으로 가정합니다.**
- **마술예장은 레벨 10 기준입니다.**
- **이벤트·캠페인의 인연 보너스는 넣지 않습니다.** 실제 획득량이 더 많을 수 있습니다.
- 아직 계산하지 않는 스킬 효과가 있습니다: 공격 시 발동하는 추가 효과, 보구 카드 종류 변경(에미야·스페이스 이슈타르), 변신, 클래스 상성 변경.

인연 포인트 계산(전열 보너스, 예장 합산, 인연 15, 찻주전자)은 실제 게임 결과와 대조해 맞는 것을 확인했습니다.

## 자주 묻는 것

**새 서번트나 이벤트가 나오면?**
앱을 열 때마다 새 한국 서버 데이터가 있는지 확인하고 자동으로 받습니다. 화면 위쪽에 데이터 기준 시각이 나옵니다.

**결과가 실제와 다른 것 같아요.**
퀘스트, 편성, 턴별로 쓴 스킬과 보구를 알려 주시면 고치는 데 큰 도움이 됩니다.

**화면이 예전 그대로예요.**
Ctrl+F5로 새로고침해 보세요.
